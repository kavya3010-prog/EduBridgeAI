EDUBRIDGE AI - EQUITABLE EDUCATION ACCESS
===========================================

This is a front-end hackathon prototype based on:
"AI for Equitable Education Access"

Features included:
- Grounded Doubt-Solving Agent demo
- Adaptive Practice Generator demo
- Teacher-Facing Insight Dashboard
- Multilingual UI demo (English/Hindi/Gujarati)
- Open educational source/citation concept
- Responsive modern design

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge/Firefox.
3. For a real AI implementation, connect the demo functions in script.js
   to an AI/RAG backend and a public/open educational content source.

This prototype is intentionally dependency-free and can be shown directly
during a hackathon presentation.
